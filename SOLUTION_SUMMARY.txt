SMS MESSAGE COLUMN VALUE EXTRACTION - SOLUTION SUMMARY
======================================================================

PROBLEM:
"I want to input a raw SMS message and get the extracted column values"

SOLUTION:
A complete SMS extraction system that extracts structured information from 
raw financial transaction SMS messages.

HOW TO USE:
-----------

1. BASIC USAGE (Text Format):
   python predict_sms.py --text "₹499 paid to Amazon"
   
   Output:
   Amount              : 499.0
   Transaction Type    : debit
   Merchant            : Amazon
   Category            : shopping

2. JSON OUTPUT:
   python predict_sms.py --text "₹499 paid to Amazon" --format json
   
   Output:
   {
     "amount": 499.0,
     "transaction_type": "debit",
     "merchant": "Amazon",
     "category": "shopping",
     "date": null,
     "reference": null
   }

3. WITH MERCHANT HINT:
   python predict_sms.py --text "Rs 1,250 debited" --merchant "Swiggy"

4. BATCH PROCESSING:
   python predict_sms.py --file sms_messages.txt --format json

EXTRACTED COLUMNS:
------------------
- amount: Transaction amount (float)
- transaction_type: debit, credit, or refund
- merchant: Merchant/vendor name
- category: shopping, food, transport, utilities, etc.
- date: Transaction date
- reference: Transaction ID or UPI reference

SUPPORTED FEATURES:
-------------------
✓ Multiple currency formats (₹, Rs, INR, $, USD)
✓ Transaction type detection
✓ Merchant name extraction
✓ Automatic categorization
✓ Date and reference extraction
✓ Multiple output formats (text, JSON, CSV)
✓ Batch processing from files
✓ Merchant hint support

PYTHON API:
-----------
from sms_extractor import SMSExtractor

extractor = SMSExtractor()
result = extractor.extract_all("₹499 paid to Amazon")

# Access extracted columns
print(result['amount'])        # 499.0
print(result['merchant'])      # Amazon
print(result['category'])      # shopping
